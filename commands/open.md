---
description: Open DesignCraft · Page Layout and optionally a workspace file
---

Open DesignCraft · Page Layout using its `open_editor` MCP tool. If `$ARGUMENTS` names a file, pass it as `path`, relative to the current workspace. Otherwise omit `path`. The panel provides interactive editing; do not claim to have edited a document merely by opening it. After the panel is ready, use this plugin's MCP tools to inspect and edit the same document. Use workspace paths for imports and saves; manual exports use the host Save As dialog. Check every tool result and saved file; do not automatically retry a timed-out edit.
