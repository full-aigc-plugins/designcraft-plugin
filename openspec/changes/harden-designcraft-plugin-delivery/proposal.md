## Why

当前插件仅封装六项技能快照，来源校验不核对 sourceProject、sourceVersion 和 releaseTag 的一致性，缺少任务编排、宿主发现与交付验收闭环。需要借鉴 Dreamina 的外部技能锁与本地 Harness 分工，在保留技能源唯一所有权的前提下形成可验证的插件交付。

## What Changes

- 保留六项外部技能，新增插件本地 designcraft-harness，复用技能源公共网关和回执，不重复安装、命令参数或错误解析实现。
- 增加本地单任务状态、证据关联、未知任务核对、显式局部修订和有条件的完成判定。
- 区分本地候选与正式发行来源；校验项目、版本、tag、commit 和内容摘要，保护用户修改及源删除边界。
- 以 Codex 作为首个宿主验收目标，补充发现元数据、入口策略和正反向场景；其他宿主按需新增独立验收。
- 增加只读运行时能力预检，使宿主加载、技能发现、固定 CLI 就绪与原生操作能力分别报告；能力缺失或版本不兼容时仅给出安全下一步，不自动安装或写入。
- 建立分发、快照、宿主、真实产物和发行证据门禁；未来市场元数据必须与实际发行身份一致。
- 参考 Dreamina 的显式能力发现和状态路由，但不引入其云端任务、账号或付费审批语义。
- 迁移旧候选状态时保留原文件；缺少可信运行身份的记录仅可只读检查，不自动执行。收紧的身份校验会有意拒绝原来被错误接受的元数据。

## Capabilities

### New Capabilities
- `plugin-harness`: 本地编排、任务状态、验收和显式修订。
- `source-provenance`: 候选/发行身份、外部与本地技能分离、受控同步。
- `host-integration`: 宿主发现、技能路由、安装缓存独立性和能力声明。
- `release-gates`: 分层验证、证据绑定、来源发布与市场一致性。

### Modified Capabilities
无既有 OpenSpec 主规范；本变更建立目标契约，不把当前快照通过当成宿主或创作验收通过。

## Impact

- 影响插件本地技能、scripts、schemas、清单、来源锁、宿主配置、测试、文档及后续 CI。
- 关联技能源 change：`designcraft-skills/openspec/changes/harden-designcraft-skill-workflows`。执行/回执/产物语义以该变更及其后同步的主规范为唯一事实源。
- 优先验证 macOS arm64 + 固定原生 0.2.1；不借用 Dreamina 历史 Windows/付费证据。
- 本次只编写规范和任务，不进行实现、安装、Git 初始化或发行。公共来源、host 安装及发布任务在对应授权和依赖证据满足后执行。
- 不创建空 MCP 声明、假 hooks 或全宿主支持声明；不引入付费审批和默认自动多轮；ArtCraft 与额外平台独立列为后续范围。
