# Harness 工作流案例

## 成功示例：范围内页面修订

- **前置：** 用户明确授权修改第 3 页标题；当前候选与现有任务身份匹配。
- **动作：** 用最新 revision 登记修订描述与受影响页面，执行 readiness；证据验证后由公开技能源入口写入工作副本。
- **预期状态：** 修订范围仍在授权内，任务迁移至 `PREPARED` 等待后续授权，不自动运行。
- **验收：** 重新核对候选摘要、工程重开、页级审阅和导出状态。

## 拒绝与恢复示例：UNKNOWN 且缺检查点

- **前置：** 任务回执为 `UNKNOWN`，持久工程检查点或步骤身份缺失。
- **动作：** 进入 `RECONCILING` 并只读检查回执、runId 和现有文件，不启动原生写入。
- **预期状态：** 原文件保留，`resumeAllowed` 为 false，任务不能回到 `EXECUTING`。
- **安全下一步：** 列出缺失的检查点/工程身份，等待可验证证据，不创建第二个任务掩盖未知状态。

以上是状态合同示例，未证明固定 CLI、真实宿主或视觉审阅已通过。
